# ClassBridge

A mobile-first classroom app for administrators, teachers, and students.

## Planned features
- Role-based dashboards
- Classes and join codes
- Assignments and completion tracking
- Attendance records
- Learning materials and notes
- Sharing from every role
- Local auto-save
- Progressive Web App support with basic offline access

## Development
This repository is being rebuilt from scratch. Secure sign-in, email verification, shared cloud data, and cross-device synchronization require a configured backend; local browser storage alone does not provide those services.
